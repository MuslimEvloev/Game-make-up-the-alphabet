## 🧠 О проекте

**Game: Make Up The Alphabet** — учебный проект на чистом **JavaScript**,  
в котором игроку нужно **составить алфавит в правильном порядке**.  
Простая, но увлекательная мини-игра для тренировки внимательности и логики.

---

## 🧩 Используемые технологии
| Технология | Роль |
|-------------|------|
| 🧱 HTML5 | структура интерфейса |
| 🎨 CSS3 | оформление элементов игры |
| ⚙️ JavaScript | логика взаимодействия и проверка результата |

---

## 🎯 Функционал
- Перетаскивание букв в правильной последовательности  
- Проверка результата и вывод сообщения о победе  
- Простая игровая логика без библиотек и фреймворков  
- Обработка пользовательских действий через DOM
